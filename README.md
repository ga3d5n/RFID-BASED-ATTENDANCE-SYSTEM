#  RFID-Based Smart Attendance System

##  Overview
The RFID-Based Smart Attendance System is an automated attendance management solution developed using Arduino and RFID technology. It identifies students through unique RFID card IDs and records their attendance, reducing manual effort and preventing errors.

##  Features
- Automatic student identification using RFID cards.
- Student details displayed on a 16×2 LCD.
- Buzzer indication for successful card scanning.
- Real-time attendance logging.
- Date and time recording in Microsoft Excel.
- Automated attendance management using PLX-DAQ.

##  Components Required
- Arduino UNO
- MFRC522 RFID Reader
- RFID Cards/Tags
- 16×2 LCD Display
- Buzzer
- Jumper Wires
- Breadboard
- USB Cable

##  Software & Technologies
- Arduino IDE
- Embedded C/C++
- RFID Technology
- PLX-DAQ
- Microsoft Excel

##  Working Principle
1. The RFID reader scans the student's RFID card.
2. The Arduino reads the unique identification number (UID).
3. The UID is verified against predefined student records.
4. Student details and attendance status are displayed on the LCD.
5. The buzzer provides an audio confirmation.
6. Attendance details, including date and time, are recorded in Microsoft Excel using PLX-DAQ.
